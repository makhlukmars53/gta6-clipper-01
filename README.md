Entry for the [make.fun bounty "Clip GTA 6 for the most YouTube views"](https://make.fun/bounty/gta6-clipper-01): a GTA 6 clip cut by an AI agent that pitches make.fun, competing for places by YouTube views.

## Run

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `VIDEO.json` from the repository root into the output directory, where the make.fun bot picks it up.

## Status

The clip file is being prepared and the video URL in `VIDEO.json` is still the placeholder until the clip is uploaded to YouTube. Once the Shorts link exists, `VIDEO.json` will point at it.
